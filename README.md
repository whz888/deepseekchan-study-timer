# 学习计时器 · DeepSeek酱

一个放在桌面上的小应用：记录每一段学习的时长，按科目/任务自动分项统计。
主页是网友二创的 DeepSeek「鲸鱼娘（蓝色大肥鱼）」Q 版形象，计时时会定期换名人名言陪你。

- **窗口很小**：500 × 760，桌面上一条，不挡事。
- **单文件**：所有样式、脚本、立绘都内联在一个 HTML 里，没有依赖、不联网。
- **数据本地**：全部存在浏览器 localStorage，关掉窗口、重启电脑都不丢。

## 怎么用

1. 输入框写下这次要学什么，例如「病理学 · 炎症」。留空点「开始」会被拦下。
2. **开始** → 计时；**暂停 / 继续** → 时间冻住再接着算；**结束** → 这一段记进统计。
3. 想换科目：点「结束当前任务，换一个」，输入新名字再开始，上一个任务自动入账。
3.5 **来回换着学**：下面统计区里的每个项目、每条明细，**点一下就回来接着记它**——
   比如先学「病理学 · 炎症」，再去「药理学」，过会儿点一下统计里的「病理学 · 炎症」，
   当前任务会自动结束并切回去，时间照旧累加到同一个项目上（正在计时的那一行显示 `● 计时中`，点了会提示）。
4. 下半部分是统计：`今日` / `累计` 两个标签切换，中间一排小柱子是近 7 天。
   每个项目显示时长和占比；`明细` 里是每一段的开始时间和时间，记错了可以点 ✕ 删掉（✕ 只删记录，不会切任务）。
5. **学习小结**：统计区那个「🌙 学习小结 · 日 / 周 / 月 · 让 DeepSeek酱 夸夸你」，
   点开是一张总结卡片，里面用三个标签切换 **今日 / 本周 / 本月**：
   - 总时长、几个科目、几段专注、连着记了几天 / 平均每天、最长的一段
   - 日柱图（本周 7 根带星期几；本月 31 根，每 5 天标一个号）
   - 各科目占比条，以及「什么时候在学」的凌晨 / 上午 / 下午 / 晚上分布
   - **📊 分析和建议**（周、月视图的最下方）：和上期比、节奏、科目结构、时段分布，
     再加上按数据给的建议
   顶上由 DeepSeek酱 用小朋友语气点评一段，喊你「大哥哥」（只夸不训）。
   认真学完一段（≥1 分钟）时这个按钮会闪一下，提醒你可以看看小结。
6. **忘了按结束也不怕**：每天 **23:59:59** 会自动替你把当天还在走的计时收尾，
   只结算到当天最后一秒，跨过午夜的部分不算 —— 第二天早上打开也不会把今天的时间算到昨天去。
   - 结算出来的那一段，标签是「23:59 收尾」，小结里会写「其中 N 段是到 23:59 自动替你收尾的」。
   - 如果 23:59 那会儿应用是关着的，**下次打开时会补收**（按当天 23:59 结算，不会把整夜算进去）。
   - 不想要这个行为，就在 ⚙ 里把「每天 23:59 自动收尾」关掉。
7. **关窗口 = 暂停**：把窗口关掉时，计时会停在那一刻（不会在后台偷偷继续跑），
   下次打开会提示「上次的「X」还没结束，先停在 N」，点「继续」接着记。
8. **忘了开计时？补记一笔**：开始按钮下面那行小字「忘了开计时？补记一笔」。
   已经学完了才发现没按开始的时候用它——
   - 填「学的是什么」（点已有的项目名会自动补全）+「补多久」（分钟，或点 15/30/45/1 小时/1.5 小时/2 小时）
   - 选**今天**还是**昨天**
   - 点「记上」，这段时长就**直接并进那个项目**里，和计时记下来的完全一样：
     进统计、进日/周/月小结、进各科目占比，**不会单独列一个「补记」分类**。
   - 明细里它就是一条普通记录（时间显示成补记那一刻往前推），点 ✕ 一样能删。
9. 右下角 ⚙：名言间隔（3/5/10/15/30 分钟）、每天 23:59 自动收尾、音效开关、导出/导入 JSON 备份、清空记录。

## 小结里的点评和分析是怎么写的

**点评**（`periodComment()`）分档 + 拼装，全程鼓励向：

| 今日时长 | 开场（日视图） |
| --- | --- |
| 0 | 咦？今天还一笔都没记耶～ 要不要先写一个小任务呀？ |
| < 5 分钟 | 哇，你坐下来开始啦！（开始最难，先夸这一步） |
| < 20 分钟 | 你学了 X 耶～小本本已经给你记上啦！ |
| < 45 分钟 | X 咯！能安安静静坐这么久，好厉害呀～ |
| < 90 分钟 | X！！你今天好认真哦，脑瓜子一直在努力转呢～ |
| < 150 分钟 | X——好厉害好厉害！你像小海豚一样不肯出来啦～ |
| < 240 分钟 | X！！！你今天像装了小马达，停都停不下来耶～ |
| ≥ 240 分钟 | X！！！超级超级厉害！三朵小红花都给你！🌸🌸🌸 |

周 / 月视图换成「大哥哥这周 / 这个月一共学了 X 哦！」+ 平均每天 + 单日之最 + 主攻科目 +
和上期对比（**少了也绝不说泄气话**，只说「是不是有点忙呀？没事的，我们慢慢来～」）+
连续天数，最后随机一句收尾（`下周 / 下个月 / 明天`我也在这儿等大哥哥哦～ 等）。
自测里有一条专门扫泄气词（`不如`/`才这么`/`太差`/`不够努力`/`懒惰`），出现就报 FOUND。

**分析和建议**（`periodAdvice()`）是纯算出来的，不靠感觉：

| 卡片 | 依据 |
| --- | --- |
| 📈 和上周 / 上月比 | 本期与上期总时长的差值和百分比；负增长写成「波动本身很正常」 |
| 📊 总量 | 上期没有记录时的兜底，把这一期说成「基线」 |
| ⏱ 节奏 | 已过 N 天里有几天有记录、平均每天、中间空掉几天 |
| 📚 科目结构 | 最大科目占比（≥70% 提醒被压扁）、最小科目 <10% 建议单独分 15 分钟 |
| 🕐 时段分布 | 凌晨 / 上午 / 下午 / 晚上四档里占比最高的那一档 |
| 💡 建议 | 平均每天 <25 / <60 / ≥60 分钟三档策略 + 空太多天 + 单段太长，各一条 |

所有周期边界都在 `periodRange()` 里算：本周 = 周一 00:00 起 7 天、本月 = 1 日 00:00 起整月、
上期为紧邻的等长区间。自测 36 / 37 用构造数据（本周内 / 上周内 / 本月早段 / 40 天前各一段）
验证「谁该进、谁不该进」。

## 功能清单

- 计时精度按真实时间戳计算，中间关掉窗口不会丢时间（关窗口即暂停，下次打开接着记）。
- **每天 23:59 自动收尾**（`autoCloseIfNeeded()`）：忘了按结束的计时，到当天最后一秒自动结算，
  只算到 23:59:59，不会把整夜算进去；关着应用的时候也会在下次打开时补收。可在 ⚙ 里关掉。
- 自动收尾的那一段会打上 `auto: 1`，明细里显示「·23:59 收尾」，小结里也会写明有几段是自动收的。
- 5 种表情随状态切换：待机 `normal`、计时中 `happy`、暂停 `think`、答错/打断 `sad`、鼓励 `cheer`。
- 35 条名言随机轮播，计时中每 N 分钟（3/5/10/15/30，可在 ⚙ 里改）自动换一条并弹提示气泡；点名言卡片也能手动换一句。
- 结束一段计时（≥1 秒才计入）会飘心 + 音效鼓励；不足 1 秒的会提示「这次太短啦」。
- 标题栏实时显示 `▶ 00:12:34 · 病理学`，任务栏最小化也能瞄一眼进度。
- 今日/累计切换、近 7 天柱状图、项目占比条、明细可删、导出/导入备份。
- **点统计里的项目或明细，直接回去接着记那一项**（时间累加到同名项目上，来回换科目不用重新输名字）。
- **学习小结：日 / 周 / 月三种周期**，各有总时长、科目数、段数、平均数、最长一段、日柱图、
  科目占比、时段分布；周 / 月多一段「📊 分析和建议」（和上期比、节奏、科目结构、时段分布 + 建议）。
- **补记**（`openBackfill()` / `doBackfill()`）：忘了开计时也能把时长补上——
  填科目 + 分钟数，选「今天 / 昨天」，点「记上」就**并进那个项目**，
  统计、小结、占比都按正常记录算，**不单独列一个「补记」分类**（记录里只多一个 `manual: 1` 字段，界面上不显示）。
- 响应式：窗口拉宽到 1000px 以上也不会破版（`max-width:520px` 居中）。

## 工程结构

```
学习计时器/
├─ src/
│  ├─ app.html        应用页面 + 样式 + 逻辑（单文件源）
│  ├─ whale.html      角色容器（按 data-exp 切换表情）
│  ├─ chara.css       9 种表情的内联 webp（base64）+ 布局
│  └─ chara/*.webp    从素材图集裁出来的表情小图
├─ tools/
│  ├─ make_chara.py   从 assets/expressions.png 裁表情、转 webp、生成 chara.css
│  ├─ make_icon.py    生成 学习计时器.ico + icon-preview.png
│  ├─ selftest.py     无头浏览器驱动点按，验证计时/暂停/换任务/持久化
│  ├─ shots.py        注入假数据 + 截图，用来检查视觉
│  └─ deploy.py       复制到桌面 + 生成快捷方式
└─ build.py           把 src/* 内联成单文件 ../学习计时器.html
```

## 重新构建

```powershell
cd 学习计时器
python tools\make_chara.py     # 素材变了才需要跑
python tools\make_icon.py      # 图标变了才需要跑
python build.py                # 生成 ..\学习计时器.html
python tools\deploy.py         # 复制到桌面并重建快捷方式
```
